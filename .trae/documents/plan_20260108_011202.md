# 城市选择组件默认值和高亮问题修复

## 问题分析
当前城市选择组件存在以下问题：
1. 当定位到深圳市时，城市选择组件打开后默认选择的是北京市广州市，而不是广东省深圳市
2. 城市选择组件打开后没有高亮显示当前选中的省份和城市

## 解决方案

### 1. 修改 `video-list.vue` 文件

#### 修改 `select_location()` 函数：
- **问题**：当前使用 `province_list.value` 来查找省份索引，可能与 `allProvinces.value` 不同步
- **解决方案**：使用 `allProvinces.value` 来查找省份索引，确保与 `getUserLocation()` 函数使用相同的省份列表

#### 修改 `updateLocationInfo()` 函数：
- **问题**：当前使用 `province_list.value` 来查找省份索引，可能与 `allProvinces.value` 不同步
- **解决方案**：使用 `allProvinces.value` 来查找省份索引，确保与 `getUserLocation()` 函数使用相同的省份列表

#### 修改城市选择弹窗通知：
- **问题**：当前通知父组件打开城市选择弹窗时，传入的 `province_list` 是 `province_list.value`
- **解决方案**：传入的 `province_list` 改为 `allProvinces.value`，确保与 `getUserLocation()` 函数使用相同的省份列表

### 2. 代码修改点

#### 修改 `select_location()` 函数：
```javascript
// 设置当前选中的省份索引 - 优化匹配逻辑
const province_index = allProvinces.value.findIndex(p => 
  p.name === selected_province.value || 
  p.name === selected_province.value.replace('省', '') ||
  p.name.replace('省', '') === selected_province.value ||
  p.name.includes(selected_province.value) ||
  selected_province.value.includes(p.name)
);
if (province_index !== -1) {
  selected_province_index.value = province_index;
}

// 通知父组件打开城市选择弹窗
emit('openCityPicker', {
  province_list: allProvinces.value,
  city_list: city_list.value,
  picker_value: picker_value.value,
  selected_province_index: selected_province_index.value,
  selected_city_index: selected_city_index.value
});
```

#### 修改 `updateLocationInfo()` 函数：
```javascript
// 更新省份索引
const provinceIndex = allProvinces.value.findIndex(p => 
  p.name === province.name || 
  p.name === province.name.replace('省', '') ||
  p.name.replace('省', '') === province.name ||
  p.name.includes(province.name) ||
  province.name.includes(p.name)
);
if (provinceIndex !== -1) {
  selected_province_index.value = provinceIndex;
}
```

## 预期效果
- 当定位到深圳市时，城市选择组件打开后会正确显示广东省深圳市
- 城市选择组件打开后会有高亮效果，显示当前选中的省份和城市
- 确保了 `selected_province_index` 与 `selected_province.value` 保持一致
- 确保了 `selected_city_index` 与 `selected_city.value` 保持一致

## 技术要点
- 使用相同的省份列表 (`allProvinces.value`) 来查找省份索引和传递给父组件，避免不同步问题
- 优化省份和城市名称的匹配逻辑，支持更多匹配方式
- 确保城市选择组件能正确接收和处理父组件传递的数据
