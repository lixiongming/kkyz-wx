# 视频滑动黑屏卡顿问题修复方案

## 问题分析

通过对比 `video-detail.vue` 和 `my-video.vue` 的代码实现，发现以下导致视频滑动黑屏卡顿的原因：

1. **视频渲染策略问题**：
   - `video-detail.vue` 渲染所有视频，随着视频数量增加，DOM节点会越来越多
   - `my-video.vue` 只渲染当前视频及其前后各一个视频，减少DOM节点数量

2. **视频上下文管理问题**：
   - `video-detail.vue` 没有使用组件实例作为视频上下文的第二个参数
   - `my-video.vue` 使用 `instance` 作为视频上下文的第二个参数，确保上下文正确绑定

3. **滑动事件处理问题**：
   - `video-detail.vue` 滑动事件处理复杂，包含异步操作和API调用
   - `my-video.vue` 滑动事件处理更简洁，直接调用 `setVideoIndex` 函数

4. **视频加载策略问题**：
   - `video-detail.vue` 每次滑动都创建新的视频上下文并尝试播放
   - `my-video.vue` 视频加载策略更优化

5. **数据管理问题**：
   - `video-detail.vue` 视频数据一次性加载，可能导致初始加载时间过长

## 解决方案

### 1. 优化视频渲染策略

修改 `video-detail.vue` 模板，只渲染当前视频及其前后各一个视频：

```vue
<view
  class="Video-box"
  :class="{ 'Video-box-vertical': item.isVerticalVideo, 'Video-box-horizontal': !item.isVerticalVideo }"
  v-if="index < video_index + 2 && index > video_index - 2"
  @click="stopVideo(item, index, $event)"
>
  <!-- 视频标签 -->
</view>

<!-- 侧边功能键和视频信息也需要添加同样的条件 -->
<image
  v-if="!item.is_play && item.video_url && item.play_video_url && !item.isSwitching && index < video_index + 2 && index > video_index - 2"
  class="iconimg3"
  src="https://kankan-cdn.mdd3.cn/images/wx-applet/home/paly-img.png"
  mode=""
  @click="stopVideo(item, index, $event)"
></image>
```

### 2. 优化视频上下文管理

在 `video-detail.vue` 中添加组件实例引用，并在创建视频上下文时使用：


### 3. 优化滑动事件处理

简化 `setVideoIndex` 函数，减少异步操作和API调用：

```vue
// 更换当前播放视频
function setVideoIndex(oldId, newId) {
  console.log('开始更换当前播放视频', { oldId, newId });
  
  // 确保新视频有数据
  if (!all_videos.value[newId]) {
    console.log('新视频不存在', newId);
    return;
  }
  
  const newVideoData = all_videos.value[newId];
  console.log('新视频数据:', newVideoData);
  
  // 下滑切换视频时，确保不显示暂停图标
  newVideoData.is_play = true;
  newVideoData.isSwitching = true;
  
  try {
    // 暂停旧视频
    console.log('尝试暂停旧视频:', oldId);
    const oldVideo = uni.createVideoContext('Video' + oldId, instance);
    if (oldVideo) {
      oldVideo.pause();
      // 更新旧视频的播放状态
      if (all_videos.value[oldId]) {
        all_videos.value[oldId].is_play = false;
        console.log('旧视频已暂停');
      }
    } else {
      console.log('创建旧视频上下文失败');
    }
  } catch (e) {
    console.error('暂停视频失败:', e);
  }
  
  // 更新当前视频索引
  video_index.value = newId;
  console.log('更新当前视频索引:', newId);
  
  // 确保新视频有播放地址
  const videoUrl = newVideoData.video_url || newVideoData.play_video_url;
  if (!videoUrl) {
    console.log('新视频没有播放地址', newId);
    newVideoData.isSwitching = false;
    return;
  }
  
  console.log('新视频播放地址:', videoUrl);
  
  // 异步调用观看接口，不阻塞视频播放
  if (newVideoData.id) {
    homeApi.getStageViewApi({ id: newVideoData.id }).then(() => {
      console.log('视频切换时观看次数统计成功');
    }).catch(err => {
      console.error('观看次数统计失败:', err);
    });
  }
  
  // 尝试播放新视频
  try {
    console.log('尝试播放新视频:', newId);
    const newVideo = uni.createVideoContext('Video' + newId, instance);
    console.log('创建新视频上下文:', newVideo);
    
    if (newVideo) {
      console.log('发送播放命令');
      // 直接播放视频
      newVideo.play();
      // 更新新视频的播放状态
      newVideoData.is_play = true;
      newVideoData.isSwitching = false;
      console.log('新视频播放命令已发送');
    } else {
      console.log('创建新视频上下文失败', newId);
      newVideoData.is_play = true;
      newVideoData.isSwitching = false;
    }
  } catch (e) {
    console.error('播放视频失败:', e);
    newVideoData.is_play = true;
    newVideoData.isSwitching = false;
  }
}
```

### 4. 优化视频加载策略

实现视频预加载策略，在当前视频播放时预加载下一个视频：

```vue
// 视频开始播放
function videoplayEvent(index) {
  if (all_videos.value.length > 0 && all_videos.value[video_index.value]) {
    all_videos.value[video_index.value].is_play = true;
  }
  closeoutsideVideo(index);
  
  // 预加载下一个视频
  preloadNextVideo(index);
}

// 预加载下一个视频
function preloadNextVideo(currentIndex) {
  const nextIndex = currentIndex + 1;
  if (nextIndex < all_videos.value.length) {
    try {
      const nextVideo = uni.createVideoContext('Video' + nextIndex, instance);
      if (nextVideo) {
        nextVideo.load();
        console.log('预加载视频:', nextIndex);
      }
    } catch (e) {
      console.error('预加载视频失败:', e);
    }
  }
}
```

### 6. 优化数据管理

实现视频数据的分页加载，避免一次性加载过多视频：

```vue
// 加载更多视频
async function loadMoreVideos() {
  if (!videoId.value || loadingMore.value) return;
  
  loadingMore.value = true;
  try {
    const randomVideos = await fetchRandomVideos(videoId.value, 10); // 每次加载10个视频
    appendVideoData(randomVideos);
  } catch (err) {
    console.error('加载更多视频错误:', err);
  } finally {
    loadingMore.value = false;
  }
}

// 手指抬起——切换视频
async function outEvent(e) {
  const newIndex = e.detail.current;
  await setVideoIndex(video_index.value, newIndex);
  
  // 滑动到最后5条时加载更多
  if (newIndex >= all_videos.value.length - 5 && !loadingMore.value) {
    loadMoreVideos();
  }
}
```
