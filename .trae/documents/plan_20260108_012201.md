# 城市选择组件默认值问题修复

## 问题分析
当前城市选择组件存在以下问题：
1. 当定位到深圳市时，城市选择组件打开后默认选择的是北京市广州市，而不是广东省深圳市
2. 城市选择组件打开后没有高亮显示当前选中的省份和城市

## 解决方案

### 修改 `init_city_list()` 函数：
- **问题**：当前使用 `allProvinces.value.find(item => item.name === provinceName)` 进行严格匹配，当省份名称格式不一致时（如 '广东' vs '广东省'），无法找到对应的省份
- **解决方案**：使用与 `updateLocationInfo()` 函数和 `select_location()` 函数相同的匹配方式，支持多种匹配逻辑

### 代码修改点

#### 修改 `init_city_list()` 函数中的省份查找逻辑：
```javascript
// 查找选中省份的 id
let selectedProvince = null;
for (const item of allProvinces.value) {
  if (item.name === provinceName || 
      item.name === provinceName.replace('省', '') ||
      item.name.replace('省', '') === provinceName ||
      item.name.includes(provinceName) ||
      provinceName.includes(item.name)) {
    selectedProvince = item;
    break;
  }
}

if (!selectedProvince) {
  console.error('未找到选中的省份:', provinceName);
  city_list.value = [
    { name: '市辖区', code: '000100' }
  ];
  selected_city_index.value = 0;
  return;
}
```

## 预期效果
- 当定位到深圳市时，城市选择组件打开后会正确显示广东省深圳市
- 城市选择组件打开后会有高亮效果，显示当前选中的省份和城市
- 确保了省份查找的准确性，无论省份名称格式如何

## 技术要点
- 使用统一的省份匹配逻辑，支持多种匹配方式
- 确保在不同函数中使用相同的省份查找方法
- 提高省份查找的准确性和可靠性
