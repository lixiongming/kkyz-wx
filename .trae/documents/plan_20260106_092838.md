# 最小改动的主包体积优化方案

## 分析当前状态
通过分析当前代码和项目结构，发现以下可能导致主包体积过大的原因：

1. **pcaData 直接导入**：video-list.vue 文件中直接导入了较大的 pca-code-min.json 文件
2. **依赖包过大**：项目使用了多个依赖包，如 animate.css、html2canvas、lodash 等
3. **可能存在未优化的导入**：存在未使用的导入或重复导入
4. **构建配置可能未完全优化**：需要检查构建配置是否启用了所有可能的优化选项

## 优化方案

### 1. 优化 pcaData 加载方式（最小改动，效果明显）
- 修改 `views/pages/home/components/video-list.vue` 文件
- 将直接导入 pcaData 改为动态加载方式
- 添加错误处理，确保在 pcaData 加载失败时不会报错
- 这是最小改动但效果明显的优化措施，因为 pcaData 是一个较大的 JSON 文件

### 2. 优化依赖包导入
- 检查项目中依赖包的使用情况
- 对于 lodash 等工具库，使用按需导入而非全量导入
- 例如：将 `import _ from 'lodash'` 改为 `import { debounce } from 'lodash'`

### 3. 移除未使用的代码和导入
- 检查项目中未使用的组件、函数和导入
- 移除这些未使用的代码，减少主包体积

### 4. 优化构建配置
- 检查并优化 `vite.config.ts` 中的构建配置
- 确保启用了所有可能的优化选项，如代码压缩、tree-shaking 等
- 考虑进一步优化代码分割策略

## 预期结果
- 主包体积显著减少，能够正常打包
- 所有功能保持完整，不会因为优化而影响用户体验
- 改动最小，仅针对关键的体积优化点进行修改
- 不需要修改分包配置，符合用户要求
