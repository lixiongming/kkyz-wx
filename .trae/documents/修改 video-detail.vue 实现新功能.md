# 修改 video-detail.vue 实现新功能

## 1. 数据获取逻辑修改
- 移除 `fetchVideoDetail` 函数，不再使用 getStageDetailApi 接口
- 修改 `fetchRandomVideos` 函数，将 num 参数默认值改为 20
- 修改 `mergeVideoData` 函数，直接使用 randomVideos 数组
- 修改 `onMounted` 函数，只调用 fetchRandomVideos 接口获取数据

## 2. 添加滚动到底部加载更多逻辑
- 修改 `outEvent` 函数，当滑动到最后一条时，重新请求接口
- 添加 `loadingMore` 状态管理
- 实现数据追加逻辑，将新数据添加到现有视频数组

## 3. UI 布局调整
- 修改顶部导航栏：
  - 左对齐标题
  - 移除右侧的分享按钮
- 修改底部视频信息：
  - 移除主力日记和主力宣言
  - 赞助方下面的数据直接使用接口的 intro 字段
  - 移除底部信息的渐变蒙层

## 4. 添加暂停图片
- 参考 `my-video.vue` 的实现，添加暂停图片
- 当视频暂停时显示暂停图片
- 点击暂停图片恢复播放

## 5. 其他优化
- 确保代码简洁，移除不必要的变量和函数
- 确保视频自动播放功能正常
- 确保暂停/播放功能正常
- 确保视频链接清理功能正常

## 具体修改点
1. **脚本部分**：修改数据获取逻辑，添加滚动加载功能
2. **模板部分**：调整顶部导航栏和底部信息布局，添加暂停图片
3. **样式部分**：移除渐变蒙层，调整布局样式

- 视频数据直接从 getStageVideoDetailRandomApi 接口获取，num 参数为 20
