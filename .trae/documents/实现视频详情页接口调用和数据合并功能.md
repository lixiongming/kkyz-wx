# 实现视频详情页接口调用和数据合并功能

## 一、修改视频详情页 (`pagesVideo/video-detail.vue`)

### 1. 添加必要的导入
- 导入 `homeApi` 模块，用于调用相关接口
- 确保已导入 `ref`、`onMounted` 等必要的Vue 3 Composition API

### 2. 添加数据状态管理
- 添加 `video_detail` 响应式变量，用于存储视频详情数据
- 添加 `related_videos` 响应式变量，用于存储随机视频列表数据
- 添加 `all_videos` 响应式变量，用于存储合并后的数据数组
- 添加 `loading` 响应式变量，用于显示加载状态
- 添加 `error` 响应式变量，用于处理错误情况

### 3. 实现接口调用逻辑
- 在 `onMounted` 钩子中获取页面参数中的 `id`
- 实现 `fetchVideoDetail` 函数，调用 `getStageDetailApi` 接口获取视频详情
- 实现 `fetchRandomVideos` 函数，调用 `getStageVideoDetailRandomApi` 接口获取随机视频列表
- 实现 `mergeVideoData` 函数，将两个接口返回的数据合并到同一个数组中

### 4. 更新页面布局

### 5. 优化用户体验
- 添加适当的加载动画

- 确保页面响应迅速

## 三、技术要点

### 1. 接口调用顺序
- 先调用 `getStageDetailApi` 获取视频详情
- 再调用 `getStageVideoDetailRandomApi` 获取随机视频列表
- 最后合并两个接口返回的数据

### 2. 数据合并逻辑
- 创建一个新数组 `all_videos`
- 将视频详情数据添加到数组的第一个位置
- 将随机视频列表数据添加到数组的后续位置
- 确保数据结构一致，便于后续使用

### 3. 错误处理
- 对每个接口调用添加错误处理
- 确保即使某个接口调用失败，页面也能正常显示
- 提供适当的错误提示

### 4. 加载状态管理
- 在接口调用开始时显示加载状态
- 在所有接口调用完成后隐藏加载状态
- 确保用户体验流畅
