# 实现视频详情页的观看次数统计和分享功能

## 需求分析
1. **观看次数统计**：
   - 用户进入页面时调用 `getStageViewApi` 接口，增加观看次数
   - 用户滑动视频切换时也需要调用 `getStageViewApi` 接口，增加观看次数
2. **分享功能**：用户点击转发时调用小程序分享功能到微信，并调用 `getStageShareApi` 接口增加分享次数
3. **分享参数**：分享时需要传入封面、标题、id 等参数
4. **分享卡片进入**：通过分享链接上的 id 参数调用接口

## 实现计划

### 1. 添加观看次数统计
- **初始加载**：在 `onMounted` 函数中，当获取到 `videoId` 后，调用 `getStageViewApi` 接口
- **视频切换**：在 `setVideoIndex` 函数中，当用户滑动切换视频时，调用 `getStageViewApi` 接口
- 接口参数：`{ id: videoId.value }`（初始加载）和 `{ id: 当前视频的 id }`（视频切换）
- 添加错误处理，确保接口调用失败不影响页面功能

### 2. 实现小程序分享功能
- 添加 `onShareAppMessage` 函数，处理发送给朋友的分享
- 添加 `onShareTimeline` 函数，处理分享到朋友圈
- 在分享函数中调用 `getStageShareApi` 接口，增加分享次数
- 分享参数包括：
  - `title`：视频标题或默认标题
  - `path`：包含视频 id 的页面路径
  - `imageUrl`：视频封面图片

### 3. 优化参数获取
- 确保页面能够正确获取从分享链接传递的 `id` 参数
- 保持现有的参数获取逻辑，同时支持分享场景

### 4. 代码修改点
- **pagesVideo/video-detail.vue**：
  - 在 `onMounted` 函数中添加初始观看次数统计逻辑
  - 在 `setVideoIndex` 函数中添加视频切换时的观看次数统计逻辑
  - 添加小程序分享相关函数
  - 确保分享参数正确设置
  - 在分享函数中调用 `getStageShareApi` 接口

## 技术实现
- 使用现有的 `homeApi.getStageViewApi` 和 `homeApi.getStageShareApi` 接口
- 遵循小程序分享功能的标准实现方式
- 保持代码结构清晰，添加适当的错误处理

## 预期效果
- 用户进入视频详情页时，观看次数自动增加
- 用户滑动切换视频时，观看次数自动增加
- 用户点击分享按钮时，可以分享到微信好友和朋友圈
- 分享时调用 `getStageShareApi` 接口增加分享次数
- 通过分享卡片进入页面时，能够正确加载对应视频并统计观看次数
