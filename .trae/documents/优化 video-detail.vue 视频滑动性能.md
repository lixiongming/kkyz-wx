# 优化 video-detail.vue 视频滑动性能方案

## 问题分析
通过对比 `my-video.vue` 和 `video-detail.vue` 的实现，发现以下性能瓶颈：

1. **暂停按钮逻辑问题**：暂停按钮显示条件过于简单，没有考虑视频是否在渲染范围内
2. **事件处理复杂**：`timeupdateEvent` 等事件处理可能过于频繁
3. **缺少 iOS 设备优化**：没有针对 iOS 设备的特殊优化
4. **状态管理冗余**：存在多个状态变量可能导致不必要的重渲染
5. **视频上下文管理**：虽然有缓存，但可能存在优化空间

## 优化方案

### 1. 优化暂停按钮显示逻辑
- 添加渲染范围限制：`v-if="!item.is_play && index < video_index + 2 && index > video_index - 2 && index === video_index"`
- 确保只有当前渲染且正在显示的视频才显示暂停按钮

### 2. 简化事件处理
- 优化 `timeupdateEvent` 函数，减少不必要的状态更新
- 只在必要时调用 `closeoutsideVideo` 函数

### 3. iOS 设备优化
- 添加 iOS 设备特殊样式类：`.myVideo-ios`
- 移除 iOS 设备上的过渡动画：`transition-property: transform !important; transition-duration: 0s !important;`

### 4. 硬件加速优化
- 为关键元素添加 `will-change: transform`
- 使用 `transform: translateZ(0)` 触发硬件加速
- 优化视频容器和播放器的 CSS 属性

### 5. 视频上下文管理优化
- 进一步优化视频上下文缓存机制
- 确保只在必要时创建和使用视频上下文
- 优化 `preloadVideos` 函数，避免过度预加载

### 6. 状态管理优化
- 减少冗余状态变量
- 优化状态更新逻辑，避免不必要的组件重渲染
- 使用计算属性提升性能

### 7. 滑动动画优化
- 确保 swiper 组件的滑动动画流畅
- 优化滑动过程中的状态管理
- 减少滑动过程中的 DOM 操作

## 实施步骤

1. **修改暂停按钮显示逻辑**：更新暂停按钮的 v-if 条件
2. **优化事件处理**：简化 `timeupdateEvent` 等事件处理函数
3. **添加 iOS 优化**：添加 `.myVideo-ios` 类和相关样式
4. **添加硬件加速**：为关键元素添加硬件加速属性
5. **优化视频上下文管理**：进一步优化视频上下文缓存
6. **优化状态管理**：减少冗余状态变量，优化状态更新
7. **测试优化效果**：在不同设备上测试视频滑动性能

## 预期效果
- 视频滑动切换更加流畅，无卡顿
- iOS 设备上的性能显著提升
- 减少不必要的 DOM 操作和重渲染
- 提升整体用户体验
