# 修改 video-detail.vue 解决三个问题

## 1. 顶部导航栏背景色修改
- 将导航栏背景色从 `rgba(0, 0, 0, 0.3)` 改为白色 `#FFFFFF`
- 将文字和图标的颜色从白色改为深色，以适应白色背景

## 2. 与小程序胶囊垂直对齐
- 在 `onMounted` 函数中添加获取胶囊位置的代码：`uni.getMenuButtonBoundingClientRect()`
- 根据胶囊位置调整导航栏的高度和内边距
- 确保箭头和文字与胶囊垂直对齐

## 3. 视频滑动到第二个无法播放的问题
- 检查 `setVideoIndex` 函数，确保正确创建和操作视频上下文
- 确保视频的 ID 生成正确，格式为 `'Video' + index`
- 检查视频的 `src` 属性，确保链接正确
- 确保 `loadMoreVideos` 函数不会影响视频播放状态

## 具体修改点
1. **脚本部分**：
   - 添加获取胶囊位置的代码
   - 修复 `setVideoIndex` 函数，确保视频切换时正确播放

2. **模板部分**：
   - 调整导航栏的样式，设置白色背景
   - 修改文字和图标的颜色

3. **样式部分**：
   - 更新导航栏样式，添加垂直对齐调整
   - 确保导航栏与胶囊对齐

## 预期效果
- 顶部导航栏背景色为白色，文字和箭头颜色为深色
- 导航栏元素与小程序胶囊垂直对齐
- 视频滑动到第二个及以后的视频时能够正常播放
- 整体布局美观，功能完整
