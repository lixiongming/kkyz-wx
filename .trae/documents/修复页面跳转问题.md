# 修复页面跳转问题

## 问题分析
通过分析代码，发现 `video-list.vue` 的 `play_video` 函数和 `Feature.vue` 的 `toUser` 函数都存在相同的问题：第一次点击可以跳转到目标页面，退出后再次点击无法跳转，需要切出页面再切回才能再次跳转。

### 可能的原因
1. **错误处理不完善**：两个函数都有 try-catch 块，但 catch 块都是空的，无法捕获和记录跳转失败的原因
2. **页面生命周期问题**：目标页面可能没有正确释放资源，导致页面栈中存在残留实例
3. **组件实例管理问题**：组件的事件处理函数可能在某些情况下失效
4. **页面跳转限制**：微信小程序对页面跳转有频率限制，特别是在快速连续跳转时

## 解决方案

### 1. 改进错误处理
- 在两个函数的 catch 块中添加错误日志记录，帮助诊断问题
- 添加用户友好的错误提示，提高用户体验

### 2. 优化跳转逻辑
- 检查目标页面是否已经在页面栈中，如果存在则使用 `uni.navigateBack` 返回到该页面
- 考虑在某些情况下使用 `uni.redirectTo` 替代 `uni.navigateTo`，避免页面栈过深

### 3. 添加调试信息
- 在跳转前后添加详细的日志记录，包括当前页面栈状态
- 添加点击次数统计，帮助分析跳转失败的规律

### 4. 页面生命周期管理
- 确保目标页面（视频详情页和store页面）在 `onUnload` 生命周期中正确释放所有资源
- 检查页面栈管理，确保页面正确入栈和出栈
