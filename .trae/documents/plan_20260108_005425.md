# 城市选择组件默认值设置修复

## 问题分析
当前城市选择组件存在以下问题：
1. 当定位成功到深圳市时，城市选择组件打开后默认选择的省是北京市、市是广州市，而不是广东省深圳市
2. 原因是 `init_city_list` 函数在初始化城市列表后，会调用 `setDefaultCity` 函数来设置默认城市，但 `setDefaultCity` 函数只对江西省和北京市做了特殊处理，其他省份默认选择第一个城市
3. 这导致了 `selected_city_index` 与 `selected_city.value` 不一致的问题

## 解决方案

### 修改 `init_city_list` 函数
- **问题**：当前 `init_city_list` 函数在初始化城市列表后，会调用 `setDefaultCity` 函数来设置默认城市，而 `setDefaultCity` 函数只对江西省和北京市做了特殊处理
- **解决方案**：修改 `init_city_list` 函数，在初始化城市列表后，根据 `selected_city.value` 来查找并设置正确的城市索引，而不是调用 `setDefaultCity` 函数

### 代码修改点

#### 修改 `video-list.vue` 文件：

1. **修改 `init_city_list` 函数**：
   - 移除调用 `setDefaultCity(provinceName)` 的代码
   - 添加代码，根据 `selected_city.value` 在城市列表中查找对应的索引
   - 如果找到，将 `selected_city_index.value` 设置为对应的索引；如果没有找到，设置为 0

2. **优化 `select_location` 函数**：
   - 确保在打开城市选择器时，使用正确的省份和城市索引
   - 确保 `picker_value` 的设置正确反映当前选中的城市

## 预期效果
- 当定位成功到深圳市时，城市选择组件打开后默认选择的是广东省深圳市
- 当定位到其他城市时，城市选择组件也能正确显示对应的省市
- 确保 `selected_city_index` 与 `selected_city.value` 保持一致

## 技术要点
- 确保城市列表初始化后，根据当前选中的城市名称设置正确的索引
- 保持组件状态的一致性，避免出现索引与实际值不匹配的情况
- 优化城市选择器的默认值设置逻辑，确保能正确反映当前定位的城市
